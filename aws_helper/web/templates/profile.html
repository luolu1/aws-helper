修改登录密码

密码经 PBKDF2-SHA256 加盐哈希存储，不可逆。修改成功后 其他设备的登录会立即失效，当前浏览器保持登录。 上次修改：{{ password_changed_at }}

要求：至少 {{ min_length }} 位，且包含大写、小写、数字、符号中的至少三类。

忘记密码怎么办

面板不做邮件找回（多一层 SMTP 依赖，且邮箱本身可能失守）。 在服务器上执行下面的命令即可重置，重置后所有会话失效： 

python3 -m aws_helper.cli reset-password              # 生成随机强密码
python3 -m aws_helper.cli reset-password --password '你的新密码'
python3 -m aws_helper.cli status                      # 查看密码/会话状态
python3 -m aws_helper.cli logout-all                  # 下线全部会话
