添加 AWS 账号

保存前会用你填的凭据（配了代理就走代理）实际调一次 DescribeRegions 校验。 Secret Key 和代理地址都用 Fernet 加密后存本地 SQLite，页面只显示掩码。 建议用最小权限 IAM 用户（EC2 权限即可，不需要账单权限）。

支持 socks5h / socks5 / socks4 / http / https。不写协议按 socks5h 处理，必须带端口。 socks5h 让域名在代理端解析，避免本地 DNS 泄漏 —— 填 socks5 会自动升级成它。留空即直连。
