DDNS 动态解析

本机公网 IP 变了自动更新 DNS 解析。适合家宽或 IP 会变的 VPS —— 域名托管在 Cloudflare，IP 一变解析跟着走，不用手动去改。 后台每 60 秒扫一遍规则，按各自间隔检查；IP 没变化不会发任何更新请求， 避免白烧 Cloudflare 的限流额度（1200 次 / 5 分钟，账号级共享）。

添加 / 更新规则

同一个（供应商 + 主机名）只存一条规则，重复提交就是更新。 保存前会实际调一次 API 校验 Token 和区域，配错当场就能看到。

用 Cloudflare 的 API Token，不是 Global API Key —— 后者是账号级全权限。控制台「我的个人资料 → API 令牌 → 创建令牌」， 选「编辑区域 DNS」模板，权限为 Zone → DNS → Edit， 区域范围只勾这一个域名即可。

不开代理时，域名会直接暴露本机真实公网 IP —— 这通常正是 DDNS 的目的。 开了代理则 TTL 强制为自动，且流量经 Cloudflare 转发。
