DDNS 动态解析

本机公网 IP 变了自动更新 DNS 解析。适合家宽或 IP 会变的 VPS —— 域名托管在 Cloudflare，IP 一变解析跟着走，不用手动去改。 后台每 60 秒扫一遍规则，按各自间隔检查；IP 没变化不会发任何更新请求， 避免白烧 Cloudflare 的限流额度（1200 次 / 5 分钟，账号级共享）。

取的是出站 IP —— 由 ip.sb 等服务回显它看到的源地址， 等价于 curl -4 https://ip.sb / curl -6 https://ip.sb。 不读网卡：NAT 后面、多网卡、走代理时网卡地址和出站地址不同， 把网卡地址写进 DNS 会解析到一个外部根本连不上的内网地址。

填写配置

填完可以二选一：生成一键脚本拿到别的机器上部署（脚本自包含， 目标机器不需要 Python、不用连这个面板），或者交给面板托管 直接更新本机的解析。

用 Cloudflare 的 API Token，不是 Global API Key —— 后者是账号级全权限。控制台「我的个人资料 → API 令牌 → 创建令牌」， 选「编辑区域 DNS」模板，权限为 Zone → DNS → Edit， 区域范围只勾这一个域名即可。

Account ID 一般不用填。DNS 记录的增删改只需要 zone id， Account ID 仅用于查 zone 时消歧义 —— 当一个 Token 能看到多个账号、 而这些账号下存在同名域名时，查询会返回多条无法确定改哪个。 真遇到时面板会明确提示你来填。控制台域名概览页右下角能找到。

不开代理时，域名会直接暴露机器的真实公网 IP —— 这通常正是 DDNS 的目的。 开了代理则 TTL 强制为自动，且流量经 Cloudflare 转发。
