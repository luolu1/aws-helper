重置实例密码

正在检查 SSM 可用性…

通过 Systems Manager 在实例内执行改密码，并顺带打开 SSH 密码登录 —— 官方云镜像默认关闭密码认证，只改密码仍然登不进去。 Ubuntu 22.04+ 会写 /etc/ssh/sshd_config.d/ 下的高优先级片段， 因为主配置会被那里的片段覆盖。重启 sshd 前会先 sshd -t 校验， 避免把自己关在门外。

前提 实例必须挂了带 AmazonSSMManagedInstanceCore 的 IAM 实例配置文件。 开机时没挂也能补：控制台「操作 → 安全 → 修改 IAM 角色」，附加后等 1-2 分钟 自动注册，不用重启。
