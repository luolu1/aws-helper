一键开机

按「系统类别 → 架构 → 镜像 → 规格」逐级选择。镜像 AMI 和实例规格都是 实时从该区域的 AWS API 拉取，不会出现选了却开不出来的情况。

Windows 管理员密码由 AWS 生成，开机后在控制台用密钥对解密获取，登录方式是 RDP（3389 端口）。 Linux 开机脚本、root 密码、apt 预装包对 Windows 无效，已自动禁用。

当前安全组：全部端口 + 全部协议对 0.0.0.0/0 开放 取消勾选可改为只放通上面填写的端口。

开机时顺带部署服务

勾选后把对应的一键脚本内联进 cloud-init，开机自动装好，不用再登录机器手动跑。 两者都是 bash + systemd，Windows 实例不支持。 部署失败不会影响开机，也不会中断你自己写的开机脚本， 失败原因留在实例的 /var/log/aws-helper-*.log。

实例自己朝境内探测，连不上才上报面板换 IP。开机后会自动在 自动换 IP 页出现一条 agent 规则。 实例 ID 由脚本从 EC2 元数据服务自己读取。

对跨境高延迟高丢包的链路提升明显。只改两条 sysctl，不换内核 —— 面板用的镜像内核都在 5.10 以上，BBR 早就编译进去了。 内核不支持时脚本会跳过并说明，不会让开机失败。

实例自己定时把公网 IP 同步到这个主机名。 一次只能给 1 台实例部署 —— 同批实例共用一份 cloud-init， 也就共用同一个主机名，开起来会互相把记录改成自己的 IP。
